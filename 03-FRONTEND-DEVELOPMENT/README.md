# FRONTEND DEVELOPMENT TOOLKIT

> **Domain Identifier**: `03-FRONTEND-DEVELOPMENT` • **Registered Skills**: `32` • **Trigger Command**: `"Activate Frontend Development Toolkit"` (/sr24 frontend)

Modern web frameworks (React, Next.js, Vue), state machines, desktop wrappers (Electron, Tauri), CSS architectures, and CWV optimization.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Architecture & State Design
- **Primary Autonomous Role**: `agency-engineering-frontend-developer`
- **Responsibilities & Output**: Establish component boundaries, caching strategies, and global state management.

### Phase 2: Component Engineering
- **Primary Autonomous Role**: `agency-engineering-senior-developer`
- **Responsibilities & Output**: Write type-safe TypeScript components, accessible DOM structures, and clean styling.

### Phase 3: Native / Desktop Packaging
- **Primary Autonomous Role**: `agency-engineering-desktop-app-engineer`
- **Responsibilities & Output**: Configure Electron or Tauri secure IPC, auto-update pipelines, and OS integration.

### Phase 4: Performance & Core Web Vitals
- **Primary Autonomous Role**: `web-performance-auditor` + `performance-optimization`
- **Responsibilities & Output**: Audit LCP, CLS, FID/INP, bundle chunking, and asset lazy loading.

### Phase 5: DevTools & Browser QA
- **Primary Autonomous Role**: `browser-testing-with-devtools`
- **Responsibilities & Output**: Automate Chrome DevTools checks, DOM layout thrashing inspection, and responsive audits.
