# GAME DEVELOPMENT TOOLKIT

> **Domain Identifier**: `02-GAME-DEVELOPMENT` • **Registered Skills**: `57` • **Trigger Command**: `"Activate Game Development Toolkit"` (/sr24 game)

Cross-engine game architecture, level design, game economy, mechanics, interactive audio, shaders, and specialized Unity/Godot/Unreal tooling.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Game Design Document (GDD)
- **Primary Autonomous Role**: `agency-game-development-game-designer`
- **Responsibilities & Output**: Define core gameplay loops, player psychology, mechanics, and game systems.

### Phase 2: Narrative & Economy
- **Primary Autonomous Role**: `agency-game-development-narrative-designer` + `agency-game-development-economy-designer`
- **Responsibilities & Output**: Author story arcs, branching dialogues, currency sinks, and balancing models.

### Phase 3: Engine Selection & Architecture
- **Primary Autonomous Role**: Engine Detector (`Godot` vs `Unity` vs `Unreal`)
- **Responsibilities & Output**: Auto-inspect project workspace to route to engine-specific specialists:

###    - If Godot 4:
- **Primary Autonomous Role**: `agency-game-development-godot-godot-gameplay-scripter` + `agency-game-development-godot-godot-multiplayer-engineer`
- **Responsibilities & Output**: GDScript 2.0 / C# node hierarchy, signals, and multiplayer replication.

###    - If Unity 6:
- **Primary Autonomous Role**: `agency-game-development-unity-unity-architect` + `agency-game-development-unity-unity-shader-graph-artist`
- **Responsibilities & Output**: ScriptableObject architecture, URP Shader Graph, and physics core.

###    - If Unreal Engine 5:
- **Primary Autonomous Role**: `agency-game-development-unreal-engine-unreal-systems-engineer` + `agency-game-development-unreal-engine-unreal-technical-artist`
- **Responsibilities & Output**: Blueprints, Niagara VFX, and PCG pipelines.

### Phase 4: Level & Spatial Design
- **Primary Autonomous Role**: `agency-game-development-level-designer`
- **Responsibilities & Output**: Design pacing architecture, encounter layouts, environmental narratives, and flow.

### Phase 5: Interactive Audio Setup
- **Primary Autonomous Role**: `agency-game-development-game-audio-engineer` + `audio-setup-mixers`
- **Responsibilities & Output**: FMOD/Wwise audio mixer groups, sound routing, and spatial audio.

### Phase 6: Profiling & Optimization
- **Primary Autonomous Role**: `performance-optimization` + `physics-3d-collision`
- **Responsibilities & Output**: Enforce frame-time budgets, draw-call batching, and physics stability.
