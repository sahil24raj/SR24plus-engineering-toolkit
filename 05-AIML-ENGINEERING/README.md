# AI/ML ENGINEERING TOOLKIT

> **Domain Identifier**: `05-AIML-ENGINEERING` • **Registered Skills**: `58` • **Trigger Command**: `"Activate AI/ML Engineering Toolkit"` (/sr24 ai)

Large Language Model post-training, prompt engineering, RAG pipelines, fine-tuning, autonomous multi-agent systems, and model evals.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Model Selection & Strategy
- **Primary Autonomous Role**: `agency-engineering-ai-engineer`
- **Responsibilities & Output**: Evaluate foundation models (Gemini, Claude, GPT, Llama) for latency, context, and cost.

### Phase 2: Systematic Prompt Engineering
- **Primary Autonomous Role**: `agency-engineering-prompt-engineer`
- **Responsibilities & Output**: Formulate system prompts, few-shot exemplars, structured JSON schemas, and chain-of-thought.

### Phase 3: RAG & Vector Data Pipelines
- **Primary Autonomous Role**: `agency-engineering-rag-pipeline-engineer`
- **Responsibilities & Output**: Build embedding chunking, hybrid keyword/vector search, and reranking pipelines.

### Phase 4: Post-Training & Fine-Tuning
- **Primary Autonomous Role**: `agency-engineering-llm-post-training-engineer`
- **Responsibilities & Output**: Design supervised fine-tuning (SFT), RLHF/RLVR preference datasets, and release gates.

### Phase 5: Autonomous Multi-Agent Systems
- **Primary Autonomous Role**: `agency-engineering-multi-agent-systems-architect`
- **Responsibilities & Output**: Orchestrate agent state machines, memory backends, tool schemas, and guardrails.
