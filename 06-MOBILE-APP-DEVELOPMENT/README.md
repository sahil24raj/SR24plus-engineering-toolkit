# MOBILE APP DEVELOPMENT TOOLKIT

> **Domain Identifier**: `06-MOBILE-APP-DEVELOPMENT` • **Registered Skills**: `13` • **Trigger Command**: `"Activate Mobile App Toolkit"` (/sr24 mobile)

Native Android & iOS applications, cross-platform frameworks, WeChat Mini-Programs, App Store Optimization, and release pipelines.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: App Architecture
- **Primary Autonomous Role**: `agency-engineering-mobile-app-builder`
- **Responsibilities & Output**: Set up clean MVVM/MVI architecture, offline-first caching, and responsive UI layouts.

### Phase 2: Platform Integration
- **Primary Autonomous Role**: `android-cli` + `compose-preview`
- **Responsibilities & Output**: Configure native Android SDKs, Gradle build files, and Jetpack Compose preview tools.

### Phase 3: WeChat & Regional Mini-Apps
- **Primary Autonomous Role**: `agency-engineering-wechat-mini-program-developer`
- **Responsibilities & Output**: Develop 小程序 (Mini Programs) with WXML, WXSS, and WeChat API authentication.

### Phase 4: App Store Optimization
- **Primary Autonomous Role**: `agency-marketing-app-store-optimizer`
- **Responsibilities & Output**: Optimize metadata, keywords, preview screenshots, and conversion funnels for App Store / Play Store.

### Phase 5: Release & CI Packaging
- **Primary Autonomous Role**: `agency-engineering-mobile-release-engineer`
- **Responsibilities & Output**: Automate keystore signing, Fastlane lanes, TestFlight, and Google Play internal track releases.
