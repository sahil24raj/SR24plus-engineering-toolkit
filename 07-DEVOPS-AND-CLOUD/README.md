# DEVOPS AND CLOUD TOOLKIT

> **Domain Identifier**: `07-DEVOPS-AND-CLOUD` • **Registered Skills**: `26` • **Trigger Command**: `"Activate DevOps & Cloud Toolkit"` (/sr24 devops)

Infrastructure automation, CI/CD deployment pipelines, SRE observability, Kubernetes/Docker, cloud platforms, and production release gates.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Infrastructure as Code (IaC)
- **Primary Autonomous Role**: `agency-engineering-platform-engineer`
- **Responsibilities & Output**: Author Terraform/Docker definitions, environment isolation, and network topology.

### Phase 2: CI/CD Pipeline Automation
- **Primary Autonomous Role**: `ci-cd-and-automation` + `agency-engineering-devops-automator`
- **Responsibilities & Output**: Configure GitHub Actions/GitLab CI workflows, test matrix runs, and automated linting.

### Phase 3: Cloud Security Architecture
- **Primary Autonomous Role**: `agency-security-cloud-security-architect`
- **Responsibilities & Output**: Enforce least-privilege IAM policies, VPC security groups, and secrets management.

### Phase 4: Site Reliability Engineering
- **Primary Autonomous Role**: `agency-engineering-sre`
- **Responsibilities & Output**: Establish Service Level Objectives (SLOs), error budgets, Prometheus metrics, and Grafana alerts.

### Phase 5: Production Launch Gate
- **Primary Autonomous Role**: `shipping-and-launch`
- **Responsibilities & Output**: Execute blue-green/canary deployment strategies and zero-downtime database migrations.
