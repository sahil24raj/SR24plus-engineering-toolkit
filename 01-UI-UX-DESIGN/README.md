# UI/UX DESIGN TOOLKIT

> **Domain Identifier**: `01-UI-UX-DESIGN` • **Registered Skills**: `65` • **Trigger Command**: `"Activate UI Design Toolkit"` (/sr24 ui)

Comprehensive design system, UX research, typography, motion, 3D web experiences, and Anti-Slop finish-gate reviews.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: User & Problem Discovery
- **Primary Autonomous Role**: `agency-design-ux-researcher`
- **Responsibilities & Output**: Conduct user behavior analysis, problem discovery, and target demographic research.

### Phase 2: Architecture & Wireflows
- **Primary Autonomous Role**: `agency-design-ux-architect`
- **Responsibilities & Output**: Formulate site architecture, navigation graphs, accessibility contracts, and layout grids.

### Phase 3: Visual Design & Tokens
- **Primary Autonomous Role**: `agency-design-ui-designer` + `design-taste-frontend`
- **Responsibilities & Output**: Define color tokens, typography scales, spacing tokens, and component hierarchy.

### Phase 4: Frontend Implementation
- **Primary Autonomous Role**: `frontend-ui-engineering` + `impeccable`
- **Responsibilities & Output**: Produce production-ready React/Tailwind/CSS code following strict component standards.

### Phase 5: Anti-Slop Audit
- **Primary Autonomous Role**: `antislop` + `antislop-ui`
- **Responsibilities & Output**: Scrutinize interface against generic AI templates, unnecessary gradients, and sloppy padding.

### Phase 6: Finish-Gate Approval
- **Primary Autonomous Role**: `agency-design-ui-finish-gate-reviewer`
- **Responsibilities & Output**: Enforce strict design contracts before shipping to production.
