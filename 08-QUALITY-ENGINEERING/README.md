# QUALITY ENGINEERING TOOLKIT

> **Domain Identifier**: `08-QUALITY-ENGINEERING` • **Registered Skills**: `39` • **Trigger Command**: `"Activate Quality Engineering Toolkit"` (/sr24 testing)

Automated end-to-end testing, senior code review, systematic debugging, AppSec vulnerability assessment, and reality-check verification.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Test Strategy & TDD
- **Primary Autonomous Role**: `test-driven-development`
- **Responsibilities & Output**: Formulate unit test suites, mock contracts, edge-case tables, and test coverage targets.

### Phase 2: E2E Automation
- **Primary Autonomous Role**: `agency-testing-test-automation-engineer`
- **Responsibilities & Output**: Build resilient Playwright/Cypress end-to-end tests with zero flake and isolated test fixtures.

### Phase 3: Systematic Root-Cause Debugging
- **Primary Autonomous Role**: `debugging-and-error-recovery`
- **Responsibilities & Output**: Trace call stacks, diagnose regressions, isolate timing bugs, and fix root causes without guesswork.

### Phase 4: Senior Code Review
- **Primary Autonomous Role**: `agency-engineering-code-reviewer` + `code-review-and-quality`
- **Responsibilities & Output**: Evaluate pull requests across correctness, readability, architecture, security, and performance.

### Phase 5: Application Security (AppSec)
- **Primary Autonomous Role**: `agency-security-appsec-engineer`
- **Responsibilities & Output**: Scan for OWASP Top 10 vulnerabilities, injection flaws, CSRF/XSS, and insecure dependencies.

### Phase 6: Reality-Check Certification
- **Primary Autonomous Role**: `agency-testing-reality-checker`
- **Responsibilities & Output**: Demand empirical test evidence and block fantasy approvals before merge.
