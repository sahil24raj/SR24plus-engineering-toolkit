# GENERAL ENGINEERING TOOLKIT

> **Domain Identifier**: `14-GENERAL-ENGINEERING` • **Registered Skills**: `60` • **Trigger Command**: `"Activate General Engineering Toolkit"` (/sr24 general)

Foundational engineering practices: Git mastery, architectural decisions (ADRs), codebase archaeology, safe refactoring, embedded systems, and documentation.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Codebase Archaeological Survey
- **Primary Autonomous Role**: `agency-specialized-codebase-archaeologist` + `agency-engineering-codebase-onboarding-engineer`
- **Responsibilities & Output**: Trace unfamiliar code paths, identify technical debt, and establish architectural baselines.

### Phase 2: Architecture Decision Records (ADR)
- **Primary Autonomous Role**: `documentation-and-adrs` + `agency-engineering-software-architect`
- **Responsibilities & Output**: Document architectural choices, trade-offs, and system boundaries in versioned ADRs.

### Phase 3: Safe Incremental Refactoring
- **Primary Autonomous Role**: `agency-engineering-minimal-change-engineer` + `code-simplification`
- **Responsibilities & Output**: Refactor complex code with surgical, minimal diffs while preserving 100% test passing.

### Phase 4: Specialized Language Hardening
- **Primary Autonomous Role**: `agency-engineering-rust-refactoring-specialist` + `build-gtk`
- **Responsibilities & Output**: Remediate compiler panics, optimize ownership models, and package low-level software.

### Phase 5: Embedded & Hardware Systems
- **Primary Autonomous Role**: `agency-engineering-embedded-firmware-engineer`
- **Responsibilities & Output**: Develop bare-metal and RTOS firmware for ESP32, STM32, ARM Cortex-M, and Arduino.
