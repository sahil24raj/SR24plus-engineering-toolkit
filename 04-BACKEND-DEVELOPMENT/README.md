# BACKEND DEVELOPMENT TOOLKIT

> **Domain Identifier**: `04-BACKEND-DEVELOPMENT` • **Registered Skills**: `48` • **Trigger Command**: `"Activate Backend Development Toolkit"` (/sr24 backend)

Scalable server architectures, API contracts (REST, GraphQL, gRPC), database optimization, authentication (OAuth/OIDC), and MCP servers.

---

## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Domain Modeling & System Architecture
- **Primary Autonomous Role**: `agency-engineering-backend-architect`
- **Responsibilities & Output**: Define domain entities, bounded contexts, and microservice/monolith topology.

### Phase 2: API & Interface Contract Design
- **Primary Autonomous Role**: `api-and-interface-design`
- **Responsibilities & Output**: Author OpenAPI/Swagger specifications, idempotent endpoint verbs, and error envelopes.

### Phase 3: Database & Index Optimization
- **Primary Autonomous Role**: `agency-engineering-database-optimizer`
- **Responsibilities & Output**: Design schema DDL, foreign key constraints, composite B-tree indexes, and query tuning.

### Phase 4: Identity & Security Hardening
- **Primary Autonomous Role**: `agency-engineering-identity-access-engineer`
- **Responsibilities & Output**: Implement OAuth 2.0/OIDC flows, JWT session validation, and RBAC authorization.

### Phase 5: MCP Tool & Server Creation
- **Primary Autonomous Role**: `agency-specialized-mcp-builder`
- **Responsibilities & Output**: Expose backend tools to AI coding agents via standardized Model Context Protocol.
