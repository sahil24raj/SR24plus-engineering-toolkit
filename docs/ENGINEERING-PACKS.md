## 1. The 14 Engineering Packs Overview

The **SR24Plus Engineering Toolkit** organizes its 413 skills into **14 domain packs**. Each pack operates as an autonomous squad that can be activated on demand via primary slash commands or natural-language triggers.

```
SR24PLUS-ENGINEERING-TOOLKIT/
├── 01-UI-UX-DESIGN/             # Design systems, Anti-Slop, Impeccable, Taste
├── 02-GAME-DEVELOPMENT/         # Unity, Godot, WebGL, Heavy Physics, Anti-Cheat
├── 03-FRONTEND-DEVELOPMENT/     # React, Next.js, WebGL 3D, TypeScript, Motion
├── 04-BACKEND-DEVELOPMENT/      # Scalable APIs, Databases, WebSockets, Identity
├── 05-AIML-ENGINEERING/         # LLM training, Prompt defense, Hybrid RAG, MCP
├── 06-MOBILE-APP-DEVELOPMENT/   # Android CLI, React Native, Mobile Device Hub
├── 07-DEVOPS-AND-CLOUD/         # CI/CD, Docker, SRE, Cost governance, Deploy
├── 08-QUALITY-ENGINEERING/      # Playwright E2E, Systematic RCA, Reality Checks
├── 09-RESEARCH-AND-ANALYTICS/   # Evidence synthesis, Trend analysis, Telemetry
├── 10-BRANDING-AND-CREATIVE/    # Brand identity, Visual storytelling, Copywriting
├── 11-PRODUCT-ENGINEERING/      # Product management, Sprints, Feature roadmaps
├── 12-SCIENCE-AND-BIOINFORMATICS# DeepMind AlphaFold, ChEMBL, PubChem, PubMed
├── 13-ANTIGRAVITY-AND-AUTOMATION# Antigravity native plugins, Swarms, Workflows
└── 14-GENERAL-ENGINEERING/      # Git hygiene, System architecture, Rust refactoring
```

## 2. Deep Dive: All 14 Domain Packs

### Pack 01 — UI/UX Design & Anti-Slop (`01-UI-UX-DESIGN`)
- **Primary Mission**: Enforce bespoke visual design standards, eliminate generic AI-generated templates, and maintain strict typographic rhythm and WCAG accessibility.
- **Assigned Skills**:
  - `impeccable`: Design critique, typography audit, spacing rhythm.
  - `antislop` & `antislop-ui`: Anti-AI-slop hard filters banning unmotivated purple gradients and cartoon emojis.
  - `taste-skill`: Color palette direction, brand alignment, visual aesthetics.
  - `ui-ux-pro-max`: 48+ curated design styles, design contracts, and accessible layouts.
  - `agency-design-ui-designer`, `agency-design-ui-finish-gate-reviewer`, `agency-design-ux-architect`.
- **Target Projects**: All web applications, landing pages, mobile apps, and SaaS dashboards.
- **Trigger Command**: `/sr24 ui [task]` or `/sr24-design [task]`
- **Natural Language Prompt**:
  > *"Review this interface for AI slop, audit color contrast against WCAG AA standards, and refine the typography scale using an 8px grid."*

### Pack 02 — Game Development (`02-GAME-DEVELOPMENT`)
- **Primary Mission**: Complete game engineering across browser WebGL, multiplayer networking, heavy vehicle physics, and Unity 3D production.
- **Assigned Skills**:
  - `browser-game-architect`: 60Hz deterministic fixed-timestep accumulator loop.
  - `websocket-multiplayer-engineer`: Authoritative Node.js server, client prediction, reconciliation.
  - `truck-physics-engineer`: 16-wheeler heavy vehicle WheelColliders, air brakes, diesel torque curves.
  - `realistic-car-controller-engineer`: Pacejka slip curves, Ackermann steering geometry.
  - `racing-track-design-engineer`: Spline circuits, banked hairpin curves ($5^\circ-12^\circ$).
  - `combat-mechanics-engineer`: 60Hz frame data, 80ms hitstop freezes, combo input buffers.
  - `browser-game-anti-cheat-engineer`: Distance delta speedhacks, memory XOR obfuscation.
  - Complete Unity Suite (32 skills): `physics-3d-collision`, `urp-postprocessing`, `shader-graph-create-custom-node`, `setup-multiplayer-services`, `setup-vivox-voice-chat`, `manage-sprite-atlas`.
- **Target Projects**: *Vibe Arena*, *Indian Truck Racing*, *Indian Politics Arena*, 2D/3D games.
- **Trigger Command**: `/sr24-game-dev [task]`, `/sr24-browser-game [task]`, `/sr24-racing-game [task]`, `/sr24-unity [task]`
- **Natural Language Prompt**:
  > *"Build a multiplayer browser battle arena with 4-digit room codes, authoritative WebSocket physics tick at 60Hz, and client prediction."*
