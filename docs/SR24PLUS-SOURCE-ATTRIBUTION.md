## 1. Provenance Statement & Attribution Principles

The **SR24Plus Engineering Toolkit** is built on open-source collaboration, integrating skills from world-class software engineers, leading tech organizations, and specialized research labs alongside bespoke SR24Plus custom architectures.

### Inviolable Attribution Rules:
1. **Zero Hallucinated Repositories**: Every referenced repository corresponds to an authentic, verified GitHub project.
2. **Clickable Upstream Traceability**: Every upstream repository name is displayed as an active clickable markdown hyperlink `[repository-name](https://github.com/owner/repository)`.
3. **Preservation of Author Rights**: Original authors, commit histories, copyright notices, and license files are 100% preserved.
4. **No Claim of Ownership**: SR24Plus does not claim ownership of upstream open-source projects. Each upstream project remains the intellectual property of its respective author or organization.
5. **License Transparency**: Explicitly delineates MIT, Apache-2.0, Unity Companion, and BSD licenses.
6. **Clear Separation of Custom Work**: Custom SR24Plus architectures (Core Intelligence engines, Indian GST/UPI billing, heavy truck physics, 60Hz anti-cheat) are distinctly demarcated from third-party open-source imports and linked to internal repository paths.
