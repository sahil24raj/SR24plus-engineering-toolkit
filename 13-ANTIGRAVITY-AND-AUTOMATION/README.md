## Autonomous Multi-Agent Workflow Pipeline

When this toolkit is activated, Antigravity coordinates the following specialized roles sequentially:

### Phase 1: Customization Discovery
- **Primary Autonomous Role**: `agy-customizations` + `antigravity_guide`
- **Responsibilities & Output**: Inspect loaded tools, plugin registries, rule priorities, and MCP servers in Antigravity.

### Phase 2: Agent Skill & Tool Creation
- **Primary Autonomous Role**: `workflow-skill-creator` + `agency-specialized-mcp-builder`
- **Responsibilities & Output**: Generate clean SKILL.md packages and standardized MCP tool definitions.

### Phase 3: Multi-Agent Swarm Orchestration
- **Primary Autonomous Role**: `native_swarm` + `agency-specialized-agents-orchestrator`
- **Responsibilities & Output**: Deploy coordinated subagent swarms with message-passing, state isolation, and shared memory.

### Phase 4: Business Automation Pipelines
- **Primary Autonomous Role**: `agency-specialized-automation-governance-architect`
- **Responsibilities & Output**: Design governed, cost-controlled workflow automations with n8n and API webhooks.

### Phase 5: Setting & Workflow Migration
- **Primary Autonomous Role**: `migrate-agent-settings` + `migrate-workflows`
- **Responsibilities & Output**: Safely upgrade legacy agent configurations, environment flags, and global skills.
